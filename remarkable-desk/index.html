Your data stays with you

reMarkable Desk is designed as a local desktop tool.

  • Private notes stay on your computer.
  • Backups remain local.
  • No automatic cloud upload of personal content.
  • No hidden synchronization of your documents.
  • Future online functions are intended only for official app content such as updates, changelogs or guidance.

Windows first. Mac and Linux are planned.

The current development focus is Windows, because it is the fastest realistic path for the first public alpha. The technical foundation is intended to be cross-platform, so Mac and Linux versions are planned later.

Windows First public alpha is being prepared for Windows.
Mac Planned after initial Windows beta feedback.
Linux Planned and likely easier to test technically than Mac.

Actively developed

reMarkable Desk is planned as a growing tool. The first public alpha is meant to show which functions are truly useful for users. Improvements, new features and reasonable user requests should be added step by step through updates.

More comfort Backup, overview, help and export workflows should become easier and more pleasant over time.
User feedback Feedback from beta users will be collected deliberately and used for further development.
More features Planned ideas include better reports, pro features, template convenience and later Mac/Linux steps.
Alpha notice: reMarkable Desk is in an early testing phase. Please use it only if you already have your own backup. It is not intended for production-critical data yet.

Will my notes be uploaded to the cloud?

No. Private notes, backups and PDFs are intended to stay locally on your computer.

Is reMarkable Desk an official reMarkable product?

No. reMarkable Desk is an independent tool for reMarkable users.

Can I download it already?

Not as a public download yet. A early access interest list is the safer first step so early tests can be handled in a controlled way.

Does it run on Mac?

Windows is being prepared first. Mac and Linux are planned, but not yet available as public test versions.
